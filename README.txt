# Тариалан хүүхдийн цэцэрлэг – Ёс зүйн дэд хороо

Энэ хувилбар нь:
- Нийтийн санал/гомдол/талархлын хуудас
- Нууц админ хуудас: /admin
- Автоматаар үүсэх QR: /qr
- Сервер дээр төвлөрсөн хариултын хадгалалттай

## Заавал хийх тохиргоо
1. Энэ хавтсыг Node.js дэмждэг хостинг дээр байршуулна.
2. ADMIN_PASSWORD орчны хувьсагчийг зөвхөн админ мэдэх хүчтэй нууц үгээр тохируулна.
3. Сайт нийтэд нээгдсэний дараа `/qr` хаяг дээр QR код автоматаар гарна.
4. Админ `/admin` хаягаар орж нууц үгээ оруулж мэдээллийг харна.

Анхаарах зүйл:
- `ADMIN_PASSWORD=CHANGE-ME-NOW` хэвээр үлдээж болохгүй.
- data/responses.json файлыг нийтэд шууд гаргахгүй; энэ серверийн public хавтаснаас тусдаа байрласан.
- Илүү өндөр хамгаалалт хэрэгтэй бол өгөгдлийн сан, HTTPS, хэрэглэгчийн бүртгэл, нөөцлөлт нэмэх нь зөв.
